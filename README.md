# Online Office Web Uygulaması

## 📋 Proje Hakkında

Bu proje, **Online Office Web** uygulamasının web arayüzünü içermektedir. Modern web teknolojileri kullanılarak geliştirilmiş olup, ofis otomasyonu ve belge yönetimi çözümleri sunar.

---

## 🚀 Teknik Özellikler

- **Frontend Framework**: Modern web framework'ü
- **Responsive Tasarım**: Mobil uyumlu arayüz
- **Office Entegrasyonu**: Microsoft Office dosya formatları desteği
- **Gerçek Zamanlı İşbirliği**: Eşzamanlı belge düzenleme
- **Bulut Depolama**: Güvenli dosya saklama ve yönetim

---

## 🔧 OfficeIMO Entegrasyonu

Bu proje, **OfficeIMO** kütüphanesi kullanılarak geliştirilmiştir:

### 📊 OfficeIMO — Open XML utilities for .NET (Word, Excel, PowerPoint, Visio)

[![CI](https://github.com/EvotecIT/OfficeIMO/actions/workflows/dotnet-tests.yml/badge.svg?branch=master)](https://github.com/EvotecIT/OfficeIMO/actions/workflows/dotnet-tests.yml)
[![codecov](https://codecov.io/gh/EvotecIT/OfficeIMO/branch/master/graph/badge.svg)](https://codecov.io/gh/EvotecIT/OfficeIMO)
[![license](https://img.shields.io/github/license/EvotecIT/OfficeIMO.svg)](LICENSE)

### 🎯 OfficeIMO ile Sağlanan Özellikler

- **📄 Word Belge İşleme**: DOCX formatında belge oluşturma ve düzenleme
- **📊 Excel Tablo Yönetimi**: XLSX dosyalarını programatik olarak işleme
- **📈 PowerPoint Sunumları**: PPTX sunumlarını dinamik olarak oluşturma
- **🔗 Visio Diyagramları**: VSDX diyagramlarını yönetme
- **⚡ Open XML Standartları**: Microsoft Office Open XML formatı desteği
